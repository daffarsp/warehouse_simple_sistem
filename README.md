# 📦 Warehouse Simple System

Warehouse Simple System adalah aplikasi sederhana berbasis **PHP Native** yang dibuat untuk membantu pengelolaan data stok barang. Aplikasi ini menyediakan fitur untuk menginput data barang, menampilkan hasil input, serta melihat daftar stok barang dalam tampilan yang sederhana dan mudah digunakan.

Project ini dikembangkan sebagai latihan dasar dalam mempelajari pemrograman web menggunakan PHP, HTML, Bootstrap, serta konsep pengolahan data menggunakan form dan array.

---

## ✨ Features

- 📥 Input Data Barang
- 📋 Menampilkan Data Barang
- 📦 Daftar Stok Barang
- 🧾 Informasi Harga Pokok & Harga Jual
- 🎨 Responsive Interface menggunakan Bootstrap
- ✨ Animasi menggunakan AOS (Animate On Scroll)

---

## 🛠️ Tech Stack

- PHP Native
- HTML5

- Bootstrap 5

## 🚀 Installation

Clone repository

```bash
git clone https://github.com/daffarsp/warehouse_simple_sistem.git
```

Masuk ke folder project

```bash
cd warehouse_simple_sistem
```

Jalankan menggunakan salah satu web server berikut:

- XAMPP
- Laragon
- WAMP

Kemudian akses melalui browser:

```
http://localhost/warehouse_simple_sistem
```
